# 🔍 meu-scanner - By Ed2219 de Luanda, Angola

Scanner de portas com Banner Grabbing feito 100% no celular usando Termux!

## O que faz?
- Escaneia portas abertas
- Pega a versão do servidor (SSH, HTTP, etc)
- Exemplo real: `SSH-2.0-OpenSSH_6.6.1p1`

## Como usar no Termux
```bash
python scanner.py scanme.nmap.org
